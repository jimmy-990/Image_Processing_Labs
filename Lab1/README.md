## About this lab

In this lab I learned the basics of programming in Python with the NumPy library, and how images are represented inside a computer as arrays of numbers.

The first part was NumPy exercises: creating different arrays such as an array of zeros, an array of ones, an array with a range of numbers, an identity matrix, random numbers, and evenly spaced points, then indexing and selection exercises to pull out a value, a row, a column, or a sub-part of an array.

The second part was about images: loading and displaying an image using OpenCV and PIL, then saving the image to disk under a new name, and finally displaying the image as a NumPy array to understand that an image is really just numbers with a shape and dimensions.

## How to run

Keep the two images img1.png and img2.png in the same folder as the notebook, then open Lab1_submit.ipynb in Jupyter and run the cells top to bottom in order.

Important note: the paths in the code are relative such as img1.png, so the images must sit right next to the notebook and not inside a subfolder, otherwise you will get an error that the image could not be read.
