# Lab 8 - Morphological Image Processing

In this lab we applied erosion, dilation, opening and closing on a binary image with 4 shapes and random noise.

## Tasks
- Task 1: applied the 4 operations using a 5x5 square kernel
- Task 2: repeated the same operations using a circular kernel (radius = 5)
- Task 3: compared the results of the two kernels

## Requirements
- Python 3
- OpenCV
- NumPy
- Matplotlib

## How to run
Open `Lab8_Morphological.ipynb` and run all cells in order.
