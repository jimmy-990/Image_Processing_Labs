# Lab 3 — Geometric & Intensity Transformations

Image processing with PIL, NumPy, and scikit-image on a grayscale test image.

## Run
```bash
pip install pillow numpy matplotlib scikit-image
```
Open the notebook and run all cells. Outputs save to the working folder.

## Tasks
- **Geometric:** scale ×2, non-uniform stretch, rotate 120°, shear
- **Intensity:** negative, log, gamma (0.4 / 1.0 / 2.5)

Image loaded from `skimage.data.camera()` — no manual download needed.
